# Oishii Nori — Table QR Ordering Links

Each table has its own link. Turn each link into a QR code and stick it on that table. When a guest scans it, the menu opens already marked for that table, and their order goes to the cashier's **Table Orders** (with a chime) for approval.

Table numbers match the Floor Plan (Dashboard → Reservations → Floor Plan).

## Printing the QR codes

- **Easiest:** Dashboard → **Reservations → Table QR Codes → Print all**. It prints all 12 codes on A4, 6 per page, each labelled "TABLE N · Scan to order".
- **Or:** paste each link above into any QR code generator.

## Notes

- **Business day:** orders only go through while the business day is open (the cashier taps **Start Business Day** on POS Terminal).
- **Wrong table numbers:** a link with a table number that doesn't exist (e.g. `?table=99`) is rejected at checkout.
- **Test first:** before sticking the codes on, scan one with a phone to check it opens the menu showing the right table.
